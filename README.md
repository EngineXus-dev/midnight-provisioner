# Nightglass Workspaces

An independent, local-first workspace manager for a Windows/Fedora dual-boot workstation, using **Fedora KDE, KVM/libvirt and trusted Distrobox environments**.

**Status:** Phase 1 foundation being imported on the `feat/nightglass-phase-01` branch. This repository is separate from Enginexus/EngineXus software and has no integration with it.

This is **not Qubes OS** and has not been security-certified. No installation scripts should change Windows partitions or UEFI boot entries automatically. The initial release provides read-only diagnostics, a GUI controller for existing VMs, and best-effort launch checks; malware containment is not guaranteed.

See the upcoming Phase 1 pull request for the application source, tests, documentation and opt-in setup scripts.
